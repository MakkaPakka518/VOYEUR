# Pixel Day–Night Toggle

Vendored from [LeiBox](https://leibox.pantoria.cn/docs/animations/pixel-toggle).
Design reference: [Zsolt Kacso](https://x.com/kaolti/status/2119151022014894260).
The included source is LeiBox's independent DOM/CSS/Canvas2D implementation; the reference design's
original source license was not verified. Preserve this notice when redistributing the component.

The ig luv integration keeps the complete particle, spring, drag, touch and keyboard behavior, but uses
a compact 572×320 logical scene scaled into a 104×58px header slot. Audio is disabled. `onCheckedChange`
synchronizes the host theme, local browser preference and both desktop/mobile switch instances.
