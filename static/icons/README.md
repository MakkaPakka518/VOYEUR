# Platform icons

Instagram, TikTok, Threads and X paths are from [Simple Icons 13.21.0](https://www.npmjs.com/package/simple-icons/v/13.21.0), licensed under [CC0-1.0](https://creativecommons.org/publicdomain/zero/1.0/). Douyin uses the same musical-note silhouette as the local TikTok mark.
The original paths are kept in the local SVG sprite; the application makes no external icon requests.
